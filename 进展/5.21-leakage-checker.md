## 今日目标

补齐 P0/release 前置的轻量 split leakage 检查入口：`scripts/check_leakage.py`。目标是让 E4/E4v3 train/dev/test 或 release JSONL 在进入主评测、附录或 release 前，能显式检查 record/source id、prompt、template、family、entity 和 holdout group 是否跨 split 重叠。

## 修改文件

- `scripts/check_leakage.py`
  - 新增 JSONL split leakage checker。
  - 支持 `--input` 单个带 `split` 字段的 release JSONL。
  - 支持重复 `--split-input SPLIT=PATH` 检查分散 split 文件。
  - 输出 JSON report，包含 split counts、字段覆盖率、overlap counts、samples、failed overlaps 和 failed coverage。
  - 默认 `--fail-on record_id,source_record_id,prompt_pair,holdout_group`，避免 release id 重命名或 metadata source id 被忽略。

## 运行命令

```bash
python -m py_compile scripts/check_leakage.py
python scripts/check_leakage.py --help

tmpdir="$(mktemp -d)"
python - <<'PY' "$tmpdir"
import json
import sys
from pathlib import Path

tmp = Path(sys.argv[1])
train = {
    "id": "train_1",
    "prompt_pos": "The answer is A.",
    "prompt_neg": "The answer is not A.",
    "template_id": "tpl_train",
    "family_id": "fam_train",
    "entity_id": "ent_train",
    "holdout_group": "hg_train",
}
clean_test = {
    "id": "test_1",
    "prompt_pos": "The answer is B.",
    "prompt_neg": "The answer is not B.",
    "template_id": "tpl_test",
    "family_id": "fam_test",
    "entity_id": "ent_test",
    "holdout_group": "hg_test",
}
leaky_test = dict(clean_test, id="test_2", holdout_group="hg_train")
source_leaky_test = dict(clean_test, id="release_renamed", holdout_group="hg_test")
source_leaky_test["metadata"] = {"source_id": "train_1"}
for name, row in [
    ("train", train),
    ("clean_test", clean_test),
    ("leaky_test", leaky_test),
    ("source_leaky_test", source_leaky_test),
]:
    (tmp / f"{name}.jsonl").write_text(json.dumps(row) + "\n", encoding="utf-8")

release_rows = [
    {
        "id": "release_train",
        "split": "train",
        "positive_prompt": "P train",
        "negative_prompt": "N train",
        "template_id": "tpl_a",
        "entity_family": "fam_a",
        "holdout_group": "hg_a",
        "metadata": {"source_id": "src_a"},
    },
    {
        "id": "release_test",
        "split": "test",
        "positive_prompt": "P test",
        "negative_prompt": "N test",
        "template_id": "tpl_b",
        "entity_family": "fam_b",
        "holdout_group": "hg_b",
        "metadata": {"source_id": "src_b"},
    },
]
(tmp / "release.jsonl").write_text(
    "".join(json.dumps(row) + "\n" for row in release_rows),
    encoding="utf-8",
)
PY

python scripts/check_leakage.py \
  --split-input "train=$tmpdir/train.jsonl" \
  --split-input "test=$tmpdir/clean_test.jsonl" \
  --report "$tmpdir/clean_report.json"

python scripts/check_leakage.py \
  --split-input "train=$tmpdir/train.jsonl" \
  --split-input "test=$tmpdir/leaky_test.jsonl" \
  --report "$tmpdir/leaky_report.json" || test "$?" -eq 1

python scripts/check_leakage.py \
  --split-input "train=$tmpdir/train.jsonl" \
  --split-input "test=$tmpdir/source_leaky_test.jsonl" \
  --report "$tmpdir/source_leaky_report.json" || test "$?" -eq 1

python scripts/check_leakage.py \
  --input "$tmpdir/release.jsonl" \
  --report "$tmpdir/release_report.json"
```

## 关键结果

- `py_compile` 通过。
- `--help` 正常显示。
- clean toy split 通过。
- holdout group 重叠 toy split 返回 exit code 1，并在 report 中记录 overlap。
- metadata `source_id` 与 train 顶层 id 重叠时返回 exit code 1，并在 report 中记录 `source_record_id` overlap。
- release toy JSONL 通过，并覆盖 `metadata.source_id` 的 `source_record_id` 检查。

## 风险和下一步

- 该脚本做 exact-match leakage 检查，不检测 paraphrase 级 prompt leakage。
- `entity_id` 只有在输入 JSONL 实际包含该字段时才可检查；release 文件若只保留 `entity_family`，需用 `source_record_id`、`family_id` 和 `holdout_group` 辅助判断。
- 下一步可在 release 导出流程后串联 `scripts/check_leakage.py --input data/release/e4v3_*.jsonl --report outputs/...json`。
