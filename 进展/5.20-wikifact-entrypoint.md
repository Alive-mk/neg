# 2026-05-20 WikiFact 标准入口补充

## 今日目标

补齐 P0 中 WikiFact OOD 评测的标准脚本入口，使后续主结果复现不必手写
`evaluate_models.py --neg-prefix "[SUPPRESS]"`。

## 修改文件

- `scripts/eval_wikifact.py`：新增薄 wrapper，复用 `scripts/evaluate_models.py`。
- `进展/5.20-wikifact-entrypoint.md`：记录入口、验证和风险。

## 运行命令

```bash
python -m py_compile scripts/eval_wikifact.py scripts/evaluate_models.py
python scripts/eval_wikifact.py --help
printf '{"models":[{"name":"generator","mode":"chat_json"}]}\n' > /tmp/neg_wikifact_wrapper_models.json
: > /tmp/neg_wikifact_wrapper_empty.jsonl
rm -f /tmp/neg_wikifact_wrapper_out.json
python scripts/eval_wikifact.py \
  --models /tmp/neg_wikifact_wrapper_models.json \
  --input /tmp/neg_wikifact_wrapper_empty.jsonl \
  --output /tmp/neg_wikifact_wrapper_out.json \
  --cache-dir /tmp/neg_wikifact_wrapper_cache
cat /tmp/neg_wikifact_wrapper_out.json
```

## 关键结果

- 默认输入：`data/external/wikifact_neg_patched.jsonl`。
- 默认输出：`outputs/eval_wikifact.json`。
- 默认缓存：`outputs/score_cache_wikifact`。
- 默认否定前缀：固定 `[SUPPRESS]`，符合 WikiFact suppress-only OOD 评测口径。
- 不新增评测指标，不改 `src/neg_blindness/evaluation.py`，不改变 WikiFact metric 定义。
- 空输入 smoke test 输出 `{}`，验证 wrapper 能把参数转发给 `evaluate_models.py` 且不加载模型。

标准运行示例：

```bash
python scripts/eval_wikifact.py \
  --models configs/model_config.json \
  --model-names qwen_rd30_os3 \
  --output outputs/eval_qwen_rd30_os3_wikifact.json
```

## 是否进入论文

作为 reproducibility / release artifact 入口可以进入复现说明；本轮没有产生新实验数字，不能单独进入论文主表。

## 风险和下一步

- 本轮只做脚本级验证，没有加载大模型重跑 WikiFact，因此不验证具体模型分数。
- `data/external/wikifact_neg_patched.jsonl` 属于本地数据路径；若要 release，需要后续确认 release 数据文件名和 schema。
- 后续可在合适 GPU 环境中用该 wrapper 重跑 Qwen/Llama/Mistral WikiFact，并与主表 JSON 对齐。
