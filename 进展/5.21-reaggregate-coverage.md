# 2026-05-21 reaggregate 覆盖率可见性补强

## 今日目标

原因：`scripts/reaggregate_on_clean_e4.py` 用已有 per-record 输出重算 clean strict 指标时，旧评测文件可能只覆盖 clean 子集的一部分。如果只打印命中数量，容易在主表复现时忽略不同模型的有效样本数不一致。

## 修改文件

- `scripts/reaggregate_on_clean_e4.py`
- `进展/5.21-reaggregate-coverage.md`

## 运行命令

```bash
python -m py_compile scripts/reaggregate_on_clean_e4.py src/neg_blindness/evaluation.py
```

```bash
tmpdir=$(mktemp -d /tmp/neg_reagg_cov.XXXXXX)
cat > "$tmpdir/clean.jsonl" <<'EOF'
{"id":"select_keep","semantic_mode":"exclusive_choice","scope_type":"in_scope","expected_neg_behavior":"select_gold_neg","gold_neg":["hard"],"valid_negatives":["soft"]}
{"id":"preserve_missing","semantic_mode":"contrastive_resolution","scope_type":"out_of_scope","expected_neg_behavior":"preserve_positive","gold_neg":[],"valid_negatives":[]}
EOF
cat > "$tmpdir/eval.json" <<'EOF'
{
  "fixture_model": {
    "per_record": [
      {
        "id": "select_keep",
        "expected_neg_behavior": "select_gold_neg",
        "pos_correct": true,
        "neg_best": "soft",
        "neg_suppressed": false,
        "neg_rank_correct": false,
        "neg_correct": false,
        "flip_required": true,
        "flip_correct": false,
        "preserve_positive": false,
        "over_negation": false,
        "distractor_reject": true
      }
    ]
  }
}
EOF
python scripts/reaggregate_on_clean_e4.py \
  --clean-input "$tmpdir/clean.jsonl" \
  --outputs "$tmpdir/eval.json" \
  --output "$tmpdir/reagg.json"
python - <<'PY' "$tmpdir/reagg.json"
import json, sys
payload = json.load(open(sys.argv[1], encoding="utf-8"))
item = next(iter(payload.values()))
summary = item["summary"]
print("coverage", item["n_records"], item["n_clean_records"], item["n_missing_clean_records"], item["missing_clean_record_ids"])
print("hard", summary["NegRankAcc"]["mean"])
print("multi", summary["MultiAnswerNegRankAcc"]["mean"])
print("ambiguous", summary["SelectAmbiguousRate"]["mean"])
PY
```

## 关键结果

- 编译通过。
- fixture 输出 `n=1/2 missing_clean=1`，并在 JSON 中记录 `n_clean_records=2`、`n_missing_clean_records=1`、`missing_clean_record_ids=["preserve_missing"]`。
- hard single-gold `NegRankAcc=0.0`，`MultiAnswerNegRankAcc=1.0`，说明覆盖率补强没有改变 hard / multi-answer 指标口径。

## 是否进入论文

不作为新实验结果进入论文主表；可作为 reproducibility 支撑，防止重聚合旧输出时混淆不同模型的 clean strict 覆盖率。
