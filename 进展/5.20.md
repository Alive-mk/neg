## 关键结果

当前仓库没有独立的 `scripts/eval_clean_strict.py`。现有等价映射如下：

| 计划入口 | 当前等价脚本 | 用途 |
| --- | --- | --- |
| `scripts/eval_clean_strict.py` | `scripts/evaluate_models.py` | 对 clean strict 输入直接跑候选排名模型评测并输出 `summary` + `per_record`。 |
| `scripts/eval_clean_strict.py` 的重聚合模式 | `scripts/reaggregate_on_clean_e4.py` | 已有 per-record 评测结果时，按 clean strict ID 子集重算主指标，避免重复跑本地模型。 |

推荐的 clean strict 直接评测命令模板：

```bash
python scripts/evaluate_models.py \
  --models configs/model_config.json \
  --input data/processed/validated_largetest_v2_clean_strict.jsonl \
  --output outputs/eval_<run_name>_clean_strict.json \
  --cache-dir outputs/score_cache_<run_name>_clean_strict \
  --model-names <model_name> \
  --neg-prefix auto
```

推荐的 clean strict 重聚合命令模板：

```bash
python scripts/reaggregate_on_clean_e4.py \
  --clean-input data/processed/validated_largetest_v2_clean_strict.jsonl \
  --outputs outputs/eval_<source_run>.json \
  --output outputs/eval_<source_run>_clean_strict_reagg.json
```

口径说明：

- clean strict 主表默认是 hard single-gold NegRank；不要给主表命令加 `--use-multi-answer-negatives`。
- `scripts/evaluate_models.py` 和 `scripts/reaggregate_on_clean_e4.py` 都会输出 `MultiAnswerNegRankAcc`，可用于 SELECT 多答案诊断，但不替代主表 hard NegRank。
- `--neg-prefix auto` 会按 `expected_neg_behavior` 注入 `[SUPPRESS]`、`[SELECT]`、`[PRESERVE]`，对应 oracle behavior token 口径。
- `scripts/eval_with_router.py` 是 router 预测 token 的下游评测入口，不等价于 clean strict oracle 主评测。
