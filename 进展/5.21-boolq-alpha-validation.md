## 今日目标

补强 BoolQ scalar PMI calibration 的可复现性防线：在读取 `outputs/eval_boolq_full_*.json` 和 `outputs/eval_boolq_full_pmi_*.json` 时，先检查模型 key、`per_record`、`prior`、`Yes/No` 分数和 calibration 参数，再进入 alpha 搜索。

## 修改文件

- `scripts/boolq_alpha_calibration.py`
- `进展/5.21-boolq-alpha-validation.md`

## 运行命令

```bash
python -m py_compile scripts/boolq_alpha_calibration.py
python scripts/boolq_alpha_calibration.py --help
python scripts/boolq_alpha_calibration.py \
  --raw-eval /tmp/boolq-calib-smoke.XXXXXX/raw.json \
  --pmi-eval /tmp/boolq-calib-smoke.XXXXXX/pmi.json \
  --model toy_model \
  --output /tmp/boolq-calib-smoke.XXXXXX/report.json \
  --folds 2 \
  --heldout-seeds 7 \
  --step 0.5 \
  --max-alpha 1.0 \
  --calibration-ratio 0.5
python scripts/boolq_alpha_calibration.py \
  --raw-eval /tmp/boolq-calib-smoke.XXXXXX/raw.json \
  --pmi-eval /tmp/boolq-calib-smoke.XXXXXX/pmi.json \
  --model missing_model \
  --output /tmp/boolq-calib-smoke.XXXXXX/bad.json \
  --folds 2
python scripts/boolq_alpha_calibration.py \
  --raw-eval /tmp/boolq-calib-smoke.XXXXXX/raw.json \
  --pmi-eval /tmp/boolq-calib-smoke.XXXXXX/pmi.json \
  --model toy_model \
  --output /tmp/boolq-calib-smoke.XXXXXX/bad_folds.json \
  --folds 3
```

## 关键结果

- 正常 smoke case 能输出 `standard`、`cross_validation`、`heldout_calibration` 等报告字段。
- 缺失模型 key 时，脚本现在明确报错：`model 'missing_model' not found in --raw-eval; available: toy_model`。
- `--folds` 大于最小标签计数时，脚本现在明确报错，避免 stratified fold 产生空标签 fold 或后续异常。
