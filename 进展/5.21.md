# 2026-05-21 进展日报

## 今日目标

为 P0 clean strict 主评测补一个薄入口脚本，降低复现实验时误用旧脚本或误开 multi-answer SELECT 口径的风险。

## 修改文件

- `scripts/evaluate_models.py`
  - 拆出 `build_parser()` 与 `run_evaluation()`，原 `main()` 行为保持不变。
  - `--use-multi-answer-negatives` 仍只在标准入口显式可选；默认仍为 hard single-gold。
- `scripts/eval_clean_strict.py`
  - 新增 clean strict wrapper，复用 `evaluate_models.py` 的 scoring、candidate set、aggregate 逻辑。
  - wrapper 不暴露 `--use-multi-answer-negatives`，因此默认固定为 Hard NegRank / single-gold SELECT 口径。

## 运行命令

```bash
python -m py_compile scripts/evaluate_models.py scripts/eval_clean_strict.py
python scripts/evaluate_models.py --help
python scripts/eval_clean_strict.py --help
```

## 关键结果

- `eval_clean_strict.py` 可作为 clean strict 主评测入口：

```bash
python scripts/eval_clean_strict.py \
  --models configs/model_config.json \
  --input data/processed/validated_largetest_v2_clean_strict.jsonl \
  --output outputs/eval_clean_strict.json \
  --cache-dir outputs/score_cache_clean_strict \
  --neg-prefix auto
```

- Multi-answer SELECT 指标没有并入该 wrapper；如需审计 multi-answer 口径，应继续显式使用：

```bash
python scripts/evaluate_models.py \
  --models configs/model_config.json \
  --input data/processed/validated_largetest_v2_clean_strict.jsonl \
  --output outputs/eval_clean_strict_multianswer.json \
  --cache-dir outputs/score_cache_clean_strict_multianswer \
  --neg-prefix auto \
  --use-multi-answer-negatives
```
