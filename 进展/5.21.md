## 运行命令

```bash
PYTHONDONTWRITEBYTECODE=1 python -B - <<'PY'
from pathlib import Path
path = Path("scripts/eval_clean_strict.py")
compile(path.read_text(encoding="utf-8"), str(path), "exec")
PY
PYTHONDONTWRITEBYTECODE=1 python -B scripts/eval_clean_strict.py --help
PYTHONDONTWRITEBYTECODE=1 python -B scripts/eval_clean_strict.py \
  --models <(printf '{"models":[]}') \
  --input <(printf '') \
  --output /tmp/neg_eval_clean_strict_smoke.json \
  --cache-dir /tmp/neg_eval_score_cache
```

## 关键结果

- 新增 `scripts/eval_clean_strict.py` 薄 wrapper，实际 scoring 和 aggregation 仍复用 `scripts/evaluate_models.py`。
- wrapper 不暴露 `--use-multi-answer-negatives`，因此 `select_gold_neg` 的主 correctness 继续使用 hard single-gold 默认口径。
- smoke run 使用 bash process substitution 提供空模型配置和空 JSONL，只验证 CLI、JSONL 读取和输出路径逻辑，不触发模型推理，也不产生仓库内 data/outputs/model 产物。
