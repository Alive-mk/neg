## 关键结果

- 新增 `scripts/eval_clean_strict.py` 薄 wrapper，复用 `scripts/evaluate_models.py` 的评测逻辑。
- 默认输入为 `data/processed/validated_largetest_v2_clean_strict.jsonl`。
- 默认 `--neg-prefix auto`，用于 oracle behavior token clean strict 主评测。
- 默认不启用 `--use-multi-answer-negatives`，因此 `NegRankAcc` 仍是 strict single-gold Hard NegRank。
- 只有显式传入 `--use-multi-answer-negatives` 时，才把 SELECT 的 `valid_negatives` 计入 multi-answer 视图。
- 轻量 fixture 指定 `generator` 时被 `evaluate_models.py` 按既有规则过滤，输出 `{}`，确认 wrapper 参数转发路径可运行且不会触发真实模型。
