# 2026-05-21 BoolQ 标准入口补齐

## 今日目标

原因：AGENTS 的最终可复现产物清单要求 `scripts/eval_boolq.py`，但仓库当前只有分散入口：`eval_boolq_negation.py` 负责 raw yes/no ranking，`eval_boolq_pmi.py` 负责 PMI 重评分，`boolq_alpha_calibration.py` 负责 scalar/held-out calibration 诊断。此前已完成 BoolQ 入口梳理日志，本轮只补一个薄 wrapper，便于后续用统一命令复现 P0 BoolQ raw / standard PMI 结果。

## 修改文件

- `scripts/eval_boolq.py`
- `进展/5.21.md`

## 运行命令

```bash
python scripts/eval_boolq.py --help
python scripts/eval_boolq.py --pmi --help
python -m py_compile scripts/eval_boolq.py scripts/eval_boolq_negation.py scripts/eval_boolq_pmi.py
```

不加载模型的 `/tmp` smoke test：

```bash
printf '{"models": []}\n' > /tmp/eval_boolq_empty_models.json
: > /tmp/eval_boolq_empty.jsonl
python scripts/eval_boolq.py \
  --models-config /tmp/eval_boolq_empty_models.json \
  --input /tmp/eval_boolq_empty.jsonl \
  --output /tmp/eval_boolq_raw_smoke.json \
  --cache-dir /tmp/eval_boolq_cache \
  --model-names missing_model
python scripts/eval_boolq.py --pmi \
  --models-config /tmp/eval_boolq_empty_models.json \
  --input /tmp/eval_boolq_empty.jsonl \
  --output /tmp/eval_boolq_pmi_smoke.json \
  --cache-dir /tmp/eval_boolq_cache \
  --model-names missing_model
```

## 关键结果

- 新增 `scripts/eval_boolq.py`，默认转发到 `scripts/eval_boolq_negation.py`，输入默认为 `data/boolq_full_val.jsonl`，输出默认为 `outputs/eval_boolq_raw.json`。
- `--pmi` 转发到 `scripts/eval_boolq_pmi.py`，默认 `--alpha 1.0`，输出默认为 `outputs/eval_boolq_pmi.json`。
- wrapper 只做 CLI 归一化，不复制模型打分逻辑，不改变 raw accuracy 或 PMI metric 定义。
- scalar PMI / held-out calibration 仍使用 `scripts/boolq_alpha_calibration.py`，不并入主入口以避免把 tuned alpha 误写成 standard PMI。
- `--help`、`py_compile`、raw 空输入 smoke 和 PMI 空输入 smoke 均通过；smoke 只验证 CLI 转发与 JSON 输出，不触发模型加载。

## 是否进入论文

不作为新实验结果进入论文主表。可进入 reproducibility appendix，作为 BoolQ raw 与 standard PMI 的标准复现入口。

## 风险和下一步

- 本轮没有运行真实 BoolQ 模型评测；真实运行需要 `data/boolq_full_val.jsonl`、本地模型权重、adapter 和 GPU。
- `configs/model_config_boolq.json` 仍含本地绝对模型路径；release 时需要用 example config 或环境映射说明替代。
- 若后续某 checkpoint 恢复 BoolQ raw 但 E4/WikiFact 下降，仍应按 AGENTS 规范归类为 training tradeoff，不能作为主模型整体改进。
