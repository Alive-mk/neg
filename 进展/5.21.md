# 2026-05-21 进展日报

## 今日目标

补齐 P0 clean strict 主评测的标准脚本入口，避免后续实验继续依赖口头映射到 `scripts/evaluate_models.py`。

## 修改文件

- `scripts/eval_clean_strict.py`：新增 thin wrapper，默认输入指向 `data/processed/validated_largetest_v2_clean_strict.jsonl`，委托 `scripts/evaluate_models.py` 执行。
- `进展/5.21.md`：记录本轮自动推进任务。

## 运行命令

```bash
python -m py_compile scripts/eval_clean_strict.py scripts/evaluate_models.py
python scripts/eval_clean_strict.py --help
python scripts/eval_clean_strict.py --print-delegated-command
```

## 关键结果

- wrapper 不暴露 `--use-multi-answer-negatives`，因此默认保持 hard single-gold 主口径。
- `NegRankAcc` / `FlipAcc` 继续由 `evaluate_models.py` 的默认 strict 逻辑计算。
- `MultiAnswerNegRankAcc` 仍由共享 aggregator 作为独立诊断字段输出，不替代 Hard NegRank。
