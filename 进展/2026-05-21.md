## 关键结果

### 1. GPU 未被使用的原因

默认 Codex sandbox 中：

```text
torch 2.9.0+cu128
cuda runtime 12.8
cuda init error: RuntimeError No CUDA GPUs are available
is_available False
count 0
```

同一命令用非 sandbox 权限运行：

```text
torch 2.9.0+cu128
cuda runtime 12.8
cuda init ok
is_available True
count 8
```

因此 GPU 空闲的直接原因是默认 sandbox 隔离了 PyTorch CUDA 初始化。后续真实 GPU 评测需要用已授权的 `python scripts/eval_clean_strict.py ...` 路径运行。

### 2. Clean strict no-token 真实评测

数据：`data/processed/validated_largetest_v2_clean_strict.jsonl`

模型：`qwen2_5_7b`

口径：`--token-mode no-token`

样本数：397

结果：

```text
PosAcc: 72.80
NegSuppRate: 42.27
NegRankAcc: 39.60
MultiAnswerNegRankAcc: 39.60
FlipAcc: 17.73
ScopeControlAcc: 87.76
OverNegationRate: 12.24
```

GPU 运行时观察到 GPU0 约 14.9GB 显存占用、约 90% 利用率。

### 3. Clean strict oracle-token 真实评测

数据：`data/processed/validated_largetest_v2_clean_strict.jsonl`

模型：`qwen2_5_7b`

口径：`--token-mode oracle`，即 `--neg-prefix auto`，使用 `expected_neg_behavior` 注入 oracle behavior token。该口径不是自动 router。

样本数：397

结果：

```text
PosAcc: 72.80
NegSuppRate: 43.30
NegRankAcc: 36.63
MultiAnswerNegRankAcc: 36.63
FlipAcc: 17.39
ScopeControlAcc: 86.73
OverNegationRate: 13.27
```

相对 no-token，当前 base Qwen2.5-7B 的 oracle token 并未带来整体提升：NegSuppRate 小幅上升，但 NegRank、FlipAcc、ScopeControlAcc 下降，OverNegationRate 上升。这符合“base 模型不能直接解释行为 token”的预期，不能当作 MGNM oracle 结果。

### 4. Leakage checker 发现真实数据风险

这些结果说明当前相关 split 不能直接宣称严格 entity/family/template/source-record holdout，需要重新定义主表使用的 split 或在论文中明确限制。

    row = {'model_label': model_label, 'json_model_key': key, 'token_mode': token_mode, 'output': str(path)}
    for m in metrics:
        v = s.get(m)
        row[m] = v.get('mean') if isinstance(v, dict) else v
        if isinstance(v, dict):
            row[m + '_lower'] = v.get('lower')
            row[m + '_upper'] = v.get('upper')

(ART / 'wikifact_patched_summary.json').write_text(json.dumps(summary, ensure_ascii=False, indent=2) + '\n')
with (ART / 'wikifact_patched_summary.csv').open('w', encoding='utf-8', newline='') as f:
    fieldnames = []
    for row in summary:
        for k in row:
            if k not in fieldnames:
                fieldnames.append(k)
    writer = csv.DictWriter(f, fieldnames=fieldnames)
    writer.writeheader()
    writer.writerows(summary)

## 关键结果

数据：`data/external/wikifact_neg_patched.jsonl`

split：WikiFact suppress-only 外部评测集，100 条，全部为 `expected_neg_behavior=suppress_target`。

口径：candidate-ranking；`wikifact_neg_patched.jsonl` 显式设置 `forbidden_neg=gold_pos`，使 WikiFact 的 `NegSuppRate` 可计算。该口径不包含 preserve/select，因此 `NegRankAcc`、`ScopeControlAcc`、`OverNegationRate` 均不适合作为本实验结论指标。

## 风险和下一步

- 本实验不回答 over-negation，因为 WikiFact patched 全部是 suppress-only，没有 `preserve_positive` 样本。
- 旧 `wikifact_neg.jsonl` 缺 `forbidden_neg`，会使 suppress 指标不可比；后续主表应统一使用 patched 或 release 化的 WikiFact eval 文件。
- 下一步建议补同口径 Llama/Mistral 或 vanilla/DPO/NC-SFT 对照，并将 WikiFact patched 口径固化为 `scripts/eval_wikifact.py` 或 release config。
