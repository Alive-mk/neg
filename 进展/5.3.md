### Prior 偏移根因分析 ✅

MGNM/DPO 训练将模型的 null prior 整体移向"No"约 0.8–1.1 个 log-prob 单位。
NC-SFT 的偏移极小（±0.06）。

| 模型 | No 偏移 | 说明 |
|---|---|---|
| qwen_base | +0.094 | 无偏 |
| qwen_mgnm | +1.055 | 强 No 偏置（suppress_target 训练副作用） |
| qwen_dpo | +1.094 | 同上 |
| llama_mgnm | +0.797 | 强 No 偏置 |
| llama_dpo | +1.088 | 强 No 偏置 |
| llama_nc_sft | −0.062 | 无偏 |

---

### PMI 校准 ✅

PMI（Pointwise Mutual Information）校准：score = log p(c|prompt) − log p(c|null)，
消除 prior 偏移。

**PMI 校准后全量 val 准确率：**

| 方法 | Qwen-PMI | Llama-PMI |
|---|---|---|
| Base | 82.9% | 74.9%* |
| DPO | 87.0% | 67.7% |
| NC-SFT | 87.6% | 85.4% |
| **MGNM (ours)** | **87.2%** | **81.4%** |

\* Llama base 天然偏向 Yes（prior_Yes > prior_No），PMI 反而不适合；
  与 MGNM 的公平对比应以原始 83.2% 为基准，gap 仅 1.8pp。

**结论：BoolQ 降级是校准伪影，非能力退化。**
- Qwen MGNM PMI（87.2%）为所有方法最高，超过 base（83.3%）
- Llama MGNM PMI（81.4%）与 base 原始（83.2%）差距缩小至 1.8pp

---

### [PRESERVE] Token 实验 ✅

尝试为 BoolQ eval 添加 `[PRESERVE]` 前缀，结果 MGNM 准确率跌至 47%（近随机）。
原因：behavior token 与 E4 任务结构深度绑定，无法迁移至 yes/no QA 格式。
Base 模型加 `[PRESERVE]` 后准确率反而略升（81%），token 被忽略视为普通文字。

### Contrastive Decoding Baseline ✅

下载 Qwen2.5-0.5B，实现 CD（Qwen-7B expert + Qwen-0.5B amateur，α=0.5）在 E4 v2 上的评测。

| 方法 | FlipAcc | ScopeCtrl | NegRank |
|---|---|---|---|
| Qwen Base | 18.4% | 86.1% | 39.6% |
| **CD (7B/0.5B, α=0.5)** | 22.7% | 71.6% | 36.6% |
| **MGNM (ours)** | **67.7%** | **91.2%** | **63.9%** |

**关键发现：** CD 对 FlipAcc 仅有微小提升（+4.3pp），且 ScopeCtrl 大幅下降（−14.5pp），
证明推理时方法无法解决表示层的否定盲目性。MGNM 训练是必要的。
