# 2026-05-21 BoolQ 数据准备 CLI 修复

## 今日目标

原因：BoolQ raw / PMI 评测前需要先生成 `data/boolq_negation.jsonl` 和 `data/boolq_full_val.jsonl`。此前 `python scripts/prepare_boolq_negation.py --help` 会直接进入 `datasets.load_dataset("boolq")`，在无网络或只读 Hugging Face cache 环境中失败，不利于轻量验证和复现入口检查。

## 修改文件

- `scripts/prepare_boolq_negation.py`：新增 argparse CLI；`--help` 在加载 BoolQ 数据前返回；新增 `--neg-output` 和 `--full-output` 参数，默认输出路径保持不变。

## 运行命令

```bash
python scripts/prepare_boolq_negation.py --help
python -m py_compile scripts/prepare_boolq_negation.py
```

## 关键结果

- 修复前，`--help` 触发 Hugging Face 请求，并在当前环境因网络/cache 权限失败。
- 修复后，`--help` 只输出 CLI 帮助，不下载、不加载数据、不写 `data/`。
- 语法编译通过。
