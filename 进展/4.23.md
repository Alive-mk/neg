**下午（R3 行为 token 消融 & R3v2 实验）**
- 对 `r3_btok` 模型运行 no-prefix 消融（GPU 7，仅推理）：
  - 去掉 prefix：NegSuppRate 96.3%→49.4%（-46.9pp，p=1.95e-9）
  - ScopeCtrl 83.8%→83.2%（不显著，p=1.00）
  - **结论：[SUPPRESS] token 是 NegSuppRate 提升的主要来源；[PRESERVE] token 对 ScopeCtrl 无增量贡献（L_preserve 已使保留成为模型的默认行为）**

- 发现 R3 btok 问题：select_gold_neg 使用 `[SUPPRESS]` token（R3v1 曾用 [SELECT]，R3v2 改为 [SUPPRESS]）
  - R3 btok (with [SELECT]): NegRankAcc=47.2%（已低于 Vanilla SFT 63.9%）
  - R3v2 (with [SUPPRESS]): NegRankAcc=28.5%（更差，模型混淆"抑制"与"排序"两项任务）
  - Llama R3v2 同样模式：NegRankAcc=29.9%，跨架构一致

- 根本原因分析：[SUPPRESS] token 在 suppress_target 中训练为"抑制目标概念"，被同一 token 用于 select_gold_neg 时，模型无法区分两项任务，导致 NegRankAcc 严重下降

**傍晚（R3v3 设计与启动）**
- 设计 R3v3：[SUPPRESS] 仅用于 suppress_target，select_gold_neg 和 preserve_positive 无 token
  - 理论基础：
    1. [SUPPRESS] 专用于 suppress_target → NegSuppRate 维持高水平
    2. select_gold_neg 无 token → 类似 Vanilla SFT 的排序学习（应恢复到 ~60%+）
    3. preserve_positive 无 token → [PRESERVE] 已证无增量效果，去除后 ScopeCtrl 不受影响
- 更新 `train_mgnm.py` 和 `evaluate_models.py` 中的 token 映射

## 关键结论

1. **[SUPPRESS] token 是 NegSuppRate 的核心驱动**（+46.9pp，高度显著）
2. **[PRESERVE] token 冗余**：L_preserve 训练使保留成为模型默认行为，token 无增量贡献
3. **行为 token 的功能解耦**：token（明确触发抑制） vs L_preserve（内化默认保留行为）
4. **select_gold_neg 的 token 方案关键**：对该任务用抑制类 token 均导致 NegRankAcc 下降（[SELECT]=47.2%，[SUPPRESS]=28.5%）；正确做法是不加 token（R3v3）
5. **跨模型一致性（Qwen vs Llama）**：R3v2 两模型 NegSuppRate 均为 100%、NegRankAcc 均约 29%、ScopeCtrl 均约 85%——行为 token 机制具有架构普适性

## Token 方案演进总结

| 版本 | 训练 token | 推理 token | NegRank | ScopeCtrl | 问题 |
|------|-----------|-----------|---------|-----------|------|
| R3 btok | [SUP]+[SEL]+[PRE] | 同 | 47.2% | 83.8% | [SEL] 对 NegRank 有干扰 |
| R3v2 | [SUP]+[SUP]+[PRE] | 同 | 28.5% | 84.4% | [SUP] 混淆 rank/suppress |
| R3v3 | [SUP]+[]+[] | 同 | 50.0% | 75.4% | 无 [PRE] 导致 ScopeCtrl 下降 |
| R3v4 (best) | [SUP]+[]+[PRE] | [SUP]+[]+[PRE] | 50.0% | 81.4% | 最优折中 |

**最终结论：**
- select_gold_neg 不需要 token（L_rank 直接驱动，token 干扰排序）
- [PRESERVE] 必须在训练 AND 推理时都存在（训练时提供判别锚点，推理时维持行为一致）
- [SUPPRESS] 是 NegSuppRate 的核心驱动（消融 p=1.95e-9）
