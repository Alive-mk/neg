### A2：Free-gen Preserve 补全 ✅

对 clean preserve 子集（`n=98`）做自由生成复核，并确认 preserve free-gen 的正确推理策略。

| 模型 | Free-gen Preserve-FlipAcc |
|------|--------------------------|
| Base | 87.8% |
| MGNM oracle `[PRESERVE]` | 85.7% |
| MGNM no token | 92.9% |

**结论：**
- preserve free-gen 不应直接加 `[PRESERVE]` 前缀；该前缀在 chat 模板里会诱发 echo / format artifact
- 候选排名仍然使用 oracle token，开放生成 preserve 则应采用 no-token 解码
- `MGNM no token = 92.9%`，已经高于 base 的 `87.8%`
- candidate-ranking ScopeCtrl 的最新主表值为 `92.9%`

**论文更新：** `tab:freegen` 及相关说明已改成“candidate ranking 用 token、preserve free-gen 不加 token”的最终口径。
