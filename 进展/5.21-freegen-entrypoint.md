# 2026-05-21 Free-generation 标准入口补充

## 今日目标

补齐 AGENTS 预期的 `scripts/eval_freegen.py` 标准入口，复用现有 suppress / preserve free-generation 评测脚本，降低后续手写命令造成口径漂移的风险。

## 修改文件

- `scripts/eval_freegen.py`：新增薄 wrapper，仅按 `--mode suppress|preserve` 分发到已有脚本。
- `进展/5.21-freegen-entrypoint.md`：记录入口、验证命令和风险。

## 运行命令

```bash
python scripts/eval_freegen.py --help
python scripts/eval_freegen.py --mode suppress --target-help
python scripts/eval_freegen.py --mode preserve --target-help
python -m py_compile scripts/eval_freegen.py scripts/evaluate_free_generation.py scripts/eval_freegen_preserve.py
```

## 关键结果

- `--mode suppress` 转发到 `scripts/evaluate_free_generation.py`，用于 `suppress_target` free-generation keyword proxy。
- `--mode preserve` 转发到 `scripts/eval_freegen_preserve.py`，用于 `preserve_positive` free-generation keyword proxy。
- wrapper 不修改生成参数、keyword overlap 代理指标、输出 JSON schema 或候选排名主指标。
- 口径提醒：suppress free-gen 的 MGNM 主诊断应使用 oracle `[SUPPRESS]`；preserve free-gen 推荐 no-token，visible `[PRESERVE]` 只作为 ablation / 失败诊断。

示例命令：

```bash
python scripts/eval_freegen.py --mode suppress -- \
  --model-path model/Qwen2.5-7B \
  --adapter-path outputs/e4_qwen_r3v5_lp15_rs3_boost_rd30_os3/adapter \
  --input data/processed/validated_largetest_v2.jsonl \
  --output outputs/eval_freegen_mgnm_oracle.json \
  --use-behavior-token

python scripts/eval_freegen.py --mode preserve -- \
  --model-path model/Qwen2.5-7B \
  --adapter-path outputs/e4_qwen_r3v5_lp15_rs3_boost_rd30_os3/adapter \
  --input data/processed/validated_largetest_v2_clean_strict.jsonl \
  --output outputs/eval_freegen_preserve_notoken.json
```

不作为新的论文结果进入主表；可进入 reproducibility appendix 或 release 脚本清单。free-generation 仍是候选排名之外的补充评测。

## 风险和下一步

- 本轮没有加载大模型，也没有重跑 free-generation；真实评测依赖本地 `data/`、`model/`、adapter 和 GPU。
- keyword coverage 是自动代理，不是完整语义评估；使用 `pass_at_5_keyword` 或 keyword-aware rerank 时只能写成 upper-bound diagnostic。
- 后续如要进入表格，应同时保留 suppress / preserve 两类输出，并明确 token setting、样本子集和是否人工审计。
