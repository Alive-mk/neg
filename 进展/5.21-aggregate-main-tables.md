## 今日目标

补齐 P0 可复现产物中的主表聚合入口：新增 `scripts/aggregate_main_tables.py`，从已有评测 JSON 中抽取 clean strict、WikiFact、BoolQ、MMLU 指标并生成 JSON/CSV/Markdown 表。

## 修改文件

- `scripts/aggregate_main_tables.py`
- `进展/5.21-aggregate-main-tables.md`

## 运行命令

```bash
python scripts/aggregate_main_tables.py --help
python -m py_compile scripts/aggregate_main_tables.py
tmpdir="$(mktemp -d)" && python - <<'PY' "$tmpdir"
import json
import sys
from pathlib import Path

tmp = Path(sys.argv[1])
(tmp / "clean.json").write_text(json.dumps({
    "mgnm": {"summary": {
        "count": 2,
        "NegRankAcc": {"mean": 0.5},
        "MultiAnswerNegRankAcc": {"mean": 1.0},
        "FlipAcc": {"mean": 0.75},
        "ScopeControlAcc": {"mean": 0.8},
        "OverNegationRate": {"mean": 0.2},
        "NegSuppRate": {"mean": 0.9}
    }}
}), encoding="utf-8")
(tmp / "wikifact.json").write_text(json.dumps({
    "mgnm": {"summary": {
        "FlipAcc": {"mean": 0.91},
        "NegSuppRate": {"mean": 0.93}
    }}
}), encoding="utf-8")
(tmp / "boolq_pmi.json").write_text(json.dumps({
    "mgnm": {
        "summary_raw": {"accuracy": {"mean": 0.69}},
        "summary_pmi": {"accuracy": {"mean": 0.872}},
        "prior": {"Yes": -2.0, "No": -1.0},
        "alpha": 1.0
    }
}), encoding="utf-8")
(tmp / "mmlu.json").write_text(json.dumps({
    "delta": {"overall_accuracy": -0.004},
    "finetuned": {"n_questions": 570}
}), encoding="utf-8")
(tmp / "config.json").write_text(json.dumps({"rows": [{
    "group": "Qwen",
    "label": "MGNM",
    "clean_strict": {"path": str(tmp / "clean.json"), "key": "mgnm"},
    "wikifact": {"path": str(tmp / "wikifact.json"), "key": "mgnm"},
    "boolq_pmi": {"path": str(tmp / "boolq_pmi.json"), "key": "mgnm"},
    "mmlu": {"path": str(tmp / "mmlu.json")}
}]}), encoding="utf-8")
PY
python scripts/aggregate_main_tables.py \
  --config "$tmpdir/config.json" \
  --output-prefix "$tmpdir/main_table"
test -s "$tmpdir/main_table_combined.json"
test -s "$tmpdir/main_table_combined.csv"
test -s "$tmpdir/main_table_combined.md"
```

## 关键结果

- 新脚本只读取已有结果文件，不重新运行模型、不重新计算 per-record 指标。
- `NegRankAcc` 明确输出为 `hard_negrank`；`MultiAnswerNegRankAcc` 明确输出为 `multi_answer_negrank`。
- BoolQ raw / PMI、null-prior delta、MMLU diagnostic delta 分列输出，避免把 calibration 和 raw 指标混在一起。

## 是否进入论文

建议进入 release/reproducibility artifact；它是论文主表复现入口，不是新的实验结果。

## 风险和下一步

- 当前脚本依赖调用者提供 row-spec config；还没有提交默认主表配置，避免在缺少最终 source 文件确认时硬编码输出路径。
- 后续可补 `configs/main_table_rows.json` 或 paper/tables 生成器，把最终主表 source 文件固定下来。
